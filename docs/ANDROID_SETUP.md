# Android setup

Requirements: Android Studio with JDK 17 and Android SDK 35; Gradle 8.9 is used in CI; AGP 8.7.3 and Kotlin 2.0.21 are pinned in Gradle configuration. Open repository root in Android Studio or run `gradle :app:assembleDebug`.

The Android app launches without backend credentials. In Settings, enter a deployed HTTPS backend URL and an already-created scoped NOVA API key. The token/base URL are encrypted with a random AES key stored in Android Keystore. To enter an Arena provider key from the phone, the NOVA key also needs `providers:read` and `providers:write`; configure `NOVA_CREDENTIAL_ENCRYPTION_KEY` on the backend first. Open **Assistant → AI provider**, paste the provider key, set an exact model ID, Save, then Test. The app sends that key over HTTPS to your backend; it is not saved in Android preferences or placed in the APK. The backend stores it encrypted in the database. Keep and back up the encryption key; without it, encrypted provider credentials cannot be recovered. API failures are shown in the UI; there is no offline AI fallback. Clear backend credentials in Settings; other navigation screens remain explicit in-development states.

Debug APK path after successful build: `app/build/outputs/apk/debug/app-debug.apk`. CI uploads it as artifact `nova-debug-apk`. This workspace has no Java/Gradle/Android SDK, so a local build has not been verified in this checkpoint.
