# GitHub Actions

`.github/workflows/android-debug.yml` runs on main pushes, pull requests and manual dispatch. It installs Temurin JDK 17 and Gradle 8.9, validates project files, runs Android unit tests and lint, builds the debug APK, verifies a non-empty APK, uploads it as `nova-debug-apk` for 14 days and publishes a job summary. It needs no private API key or signing credential. `.github/workflows/backend.yml` installs Python 3.11 dependencies and runs repository tests.

Both workflows have run on PR #1: backend validation passed and the Android workflow passed test/lint/assemble plus APK existence verification. The successful Android run produced a 16,448,412-byte `nova-debug-apk` artifact (14-day retention): https://github.com/rsak0730-cmyk/2D-AGENT/actions/runs/45045951618. APK was not downloaded or installed on a device in this sandbox, so device launch is not verified. The Android build is not locally verified because the workspace lacks JDK/SDK. Future release signing must use protected GitHub environment secrets and a separate reviewed workflow; do not commit keystores, passwords, or production signing material.
