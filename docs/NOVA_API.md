# NOVA API (current)

FastAPI serves OpenAPI at `/openapi.json` and Swagger at `/docs`. API version prefix is `/api/v1`. Implemented operations: admin create/list/revoke scoped NOVA keys; per-token Arena provider-key settings (write encrypted credential, get masked configuration status, test against provider model-list endpoint, remove override); create/list/delete agents; create/list/read tasks; update a task checkpoint/state; call the configured provider-backed chat completion; create/continue, list, search, read and delete conversations isolated to the calling API key; authenticated WebSocket `/api/v1/events` broadcasts task checkpoint updates. `/health` checks database connectivity and whether provider credentials are configured.

All assistant/task/agent endpoints use scopes. Current key scopes: `assistant:read`, `assistant:write`, `providers:read`, `providers:write`, `tasks:read`, `tasks:write`, `agents:read`, `agents:write`, `office:read`, `events:read`; unused scopes do not imply capabilities. Mobile provider setup currently supports Arena only. `NOVA_CREDENTIAL_ENCRYPTION_KEY` must be configured server-side for encrypted database storage; it is never sent to the phone. Key creation/revocation require `NOVA_ADMIN_TOKEN`. Raw key is returned only once and hashed at rest. API limits are process-local only. Conversation context is limited to the last 20 successful turns. Tasks are records/checkpoints, not executing jobs. No reminders, automation, project files, API usage history, audit endpoint or mobile API-key management UI exists yet. Use HTTPS in production and never treat model-provider quota as NOVA quota.
