## Known boundaries — do not claim complete

- Task execution supports API-triggered runs and the separate database-backed polling worker (`python -m nova_api.queue_worker` / Compose `worker`). Owner-scoped task prerequisites, dependency-aware parallel batches, checkpoints/progress, leases/heartbeats, lease-expiry recovery with exact-match completed-output reuse, and bounded retry backoff are tested. PostgreSQL capacity checks use transaction advisory locks; a live multi-replica stress test is not available. PostgreSQL `LISTEN`/`NOTIFY` event fan-out is installed by migration 0008; SQLite remains single-process. Cancellation/employee stop are cooperative between provider calls.
- Android Tasks now exposes dependency selection, persisted progress, results, retry, and cancel; Agents exposes pause/resume and cooperative stop. Android compilation remains blocked in this sandbox because Java/JAVA_HOME and Android SDK are unavailable.
- The compatibility gateway is not full OpenAI/Anthropic parity: it is text-only; tool calls, multimodal content, stop-sequence controls, provider-specific extensions, Gemini/Cloudflare streaming, and reconnect/resume of an interrupted generation are unsupported. A retry begins a new provider generation. Claude Desktop and real upstreams have not been live-tested. Multi-gateway profiles, employee-specific fallback-model lists, circuit breakers, and a full gateway administration dashboard remain unimplemented.
- Provider token counts are recorded as zero where the provider usage metadata is not consumed; costs are not guessed. Provider and owner request ceilings are enforced, provider-level quotas remain authoritative.
- Memory is keyword/text notes, not vector search. Project memory is not automatically injected into task prompts. Workers can use only the explicitly permitted deterministic `math.calculate`, `text.analyze`, and `memory.search` tools. No shell, filesystem, browser, arbitrary network, MCP, or external action tool is implemented; the safe tool registry is not an approval workflow for future high-risk actions.
- Headquarters shows saved room/furniture/employee positions, backend-validated routes, and task-start workstation movement. Persisted meeting schedules/invitations/transcripts/shared context/handoffs are available in Android HQ. Employee pause/resume and cooperative task stop are connected. Meeting-room movement, furniture-object-specific actions, directional sprite orientation, and direct worker profile/model controls remain as previously implemented; task creation now supports a preferred primary worker.
- Admin infrastructure endpoint uses the backend bootstrap secret and reports this process' DB/task/provider/usage counts; it is not a distributed cluster monitor.
- PostgreSQL migration is manual; existing SQLite databases are not migrated by `create_all`.
- Free tier/usage is provider/account/model-dependent. Current provider documentation and limitations are in `docs/PROVIDERS.md`; no live provider test is run in CI.
